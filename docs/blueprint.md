# **App Name**: Ateme Titan Configurator

## Core Features:

- Template Selection: Allow users to select from a list of predefined Ateme Titan Live JSON templates (4K H264 - A, 4K H265 - A, 4K H264 - B, 4K H265 - B, HD H264, HD H265).
- Site Configuration: Enable users to select a site (HN or HCM) which will automatically update the UDP IP addresses in the JSON to follow the patterns 225.3.1.x:30xxx for HN and 225.4.1.x:30xxx for HCM.
- IP Output Customization: Provide a UI to configure output IP addresses with the following values 27, 28, 30, 31, 32, 33, 34, 35, 36, 37, 100, 101, 5, 6, 73, 76, 77, which are used in conjunction with the site to complete the IP configuration.
- Logo Selection: Let users select a logo from predefined options (FPT-Play-TT, FPT-Play-TTDQ, FPT-TT-EPL).
- Logo Position Selection: Allow users to choose the logo position (top right, bottom right, top left, bottom left, EPL).
- JSON Generation and Download: Generate a new JSON file based on the user's selections and provide a download link.

## Style Guidelines:

- Primary color: Deep Blue (#2E3192) to represent stability and professionalism in configuration.
- Background color: Light Gray (#E0E0E0), a subtle background to allow content to stand out without distraction. 
- Accent color: Soft Green (#8FBC8F), analogous to blue, it introduces a contrasting highlight for interactive elements and successful operations, symbolizing accuracy and efficiency.
- Font: 'Inter', a sans-serif font known for its clarity and readability in UIs; suitable for both headlines and body text. 
- Use simple, clear icons for each configurable parameter to provide a visual aid.
- A clean, structured layout to help guide users through each step of the configuration process.
- Subtle animations, such as a progress bar, to indicate the status of the JSON generation process.
